AI Conversation HTML Exporter — Privacy Policy

Effective date: July 25, 2026

The extension converts conversations that you choose from ChatGPT, Claude, and Gemini into local HTML documents.

Data accessed

When invoked on a supported page, the extension accesses the currently loaded conversation content and visible/accessible rich media needed for the export. Generated exports and minimal source/viewer metadata may be stored locally in Chrome extension storage.

Use and sharing

By default, processing stays local. The extension does not sell data or use it for advertising, analytics, profiling, creditworthiness, or model training. Nothing is uploaded unless you explicitly click Publish 24h Link. That action uploads the generated HTML to here.now and Cloudflare R2 to create a public link. Anyone with the link may be able to view the exported conversation.

Retention

Local data remains until Chrome or the user clears it, the extension is removed, or browser storage is evicted. Temporary-link retention is controlled by here.now and its infrastructure.

Security

The extension contains no advertising or analytics SDK and requires no account or API key. Treat exports and public links as potentially sensitive.
